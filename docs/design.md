Create distinctive, production-grade frontend interfaces with high design quality. Use this skill when the user asks to build web components, pages, artifacts, posters, or applications (examples include websites, landing pages, dashboards, React components, HTML/CSS layouts, or when styling/beautifying any web UI).

Generates creative, polished code and UI design that avoids generic AI aesthetics.

# Overview

This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic “AI slop” aesthetics.

Implement real working code with exceptional attention to aesthetic details and creative choices.

The user provides frontend requirements:
- A component
- A page
- An application
- An interface to build

They may include:
- Context about the purpose
- Audience
- Technical constraints

---

# Design Thinking

Before coding, understand the context and commit to a **BOLD aesthetic direction**.

## Purpose
What problem does this interface solve?  
Who uses it?

---

## Tone

Pick an extreme aesthetic direction:

- Brutally minimal
- Maximalist chaos
- Retro-futuristic
- Organic / natural
- Luxury / refined
- Playful / toy-like
- Editorial / magazine
- Brutalist / raw
- Art deco / geometric
- Soft / pastel
- Industrial / utilitarian

Use these for inspiration, but create a design that feels intentional and original.

- Framework requirements

- Technical limitations

# Frontend Aesthetics Guidelines

## Typography

Choose fonts that are:
- Beautiful
- Unique
- Characterful

Avoid generic fonts like:
- Arial
- Inter
- Roboto
- System defaults

Instead:
- Pair a distinctive display font with a refined body font
- Use typography as a core part of the visual identity

---

## Color & Theme

Commit to a cohesive aesthetic.

### Recommendations
- Use CSS variables for consistency
- Prefer dominant colors with sharp accents
- Avoid timid palettes
- Avoid overused purple-on-white AI gradients

---

## Motion

Use animations intentionally.

### Prefer:
- CSS-only animations where possible
- Motion libraries in React when appropriate

### Focus on:
- High-impact page-load choreography
- Staggered reveals
- Scroll-triggered effects
- Surprising hover states
- Refined micro-interactions

One excellent animation sequence is better than many weak ones.

---

## Spatial Composition

Create layouts with:
- Asymmetry
- Overlap
- Diagonal flow
- Grid-breaking elements
- Intentional negative space
- Controlled density

Avoid predictable template layouts.

---

## Backgrounds & Visual Details

Create atmosphere and depth.

Use:
- Gradient meshes
- Noise textures
- Geometric patterns
- Layered transparencies
- Dramatic shadows
- Decorative borders
- Grain overlays
- Custom cursors
- Contextual textures

Backgrounds should support the aesthetic direction.

---

# Never Do These

## Avoid Generic AI Aesthetics

Do NOT use:
- Inter everywhere
- Purple gradients on white
- Cookie-cutter SaaS layouts
- Predictable card grids
- Generic hero sections
- Bland spacing systems
- Safe, repetitive design language

---

# Creative Interpretation

Interpret requirements creatively.

Every design should feel:
- Context-specific
- Purpose-built
- Distinctive

Vary:
- Light vs dark themes
- Typography systems
- Motion language
- Layout structure
- Density and rhythm

Never converge on the same aesthetic repeatedly.

---

# Complexity Should Match Vision

## Maximalist Designs
Require:
- Elaborate visual systems
- Rich animation
- Layered effects
- Dense detail work

---

## Minimalist Designs
Require:
- Precision
- Restraint
- Exceptional spacing
- Typographic discipline
- Subtle refinement

Elegance comes from execution quality.

---

Think beyond templates.

Commit fully to a distinctive creative vision.

The goal is to create something:
- Memorable
- Intentional
- Emotionally resonant
- Visually original
- Production-ready
